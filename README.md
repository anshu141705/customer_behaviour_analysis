# customer_behaviour_analysis


## Overview

This project demonstrates a complete end-to-end data analytics workflow. It involves loading and exploring a dataset using Python, cleaning and preprocessing the data, performing SQL analysis in MySQL, and creating an interactive Power BI dashboard to present key insights.

The project highlights practical skills in data cleaning, exploratory data analysis (EDA), SQL querying, and data visualization.

---

## Dataset

The dataset contains structured business data used for analysis and reporting.

The analysis focuses on:

* Understanding the dataset structure
* Identifying missing values and duplicates
* Cleaning and preparing the data
* Extracting meaningful business insights
* Building an interactive dashboard

## Project Workflow

### 1. Data Loading

* Imported the dataset into Python.
* Explored the dataset structure and data types.

### 2. Exploratory Data Analysis (EDA)

* Generated descriptive statistics.
* Analyzed missing values.
* Identified duplicate records.
* Visualized distributions and relationships using charts.

### 3. Data Cleaning

* Handled missing values.
* Removed duplicate records.
* Corrected inconsistent data.
* Prepared the dataset for analysis.

### 4. SQL Analysis

* Imported the cleaned dataset into MySQL.
* Wrote SQL queries to answer business questions.
* Used filtering, aggregation, grouping, sorting, and joins (where applicable).

### 5. Power BI Dashboard

* Connected the cleaned dataset to Power BI.
* Created interactive visualizations.
* Added filters and slicers for better user interaction.
* Designed a dashboard to highlight important KPIs and trends.

## How to Run

1. Clone this repository.
2. Install the required Python libraries.
3. Open the Jupyter Notebook (or Google Colab notebook).
4. Run all notebook cells to perform data loading, EDA, and data cleaning.
5. Import the cleaned dataset into MySQL and execute the SQL queries.
6. Open the Power BI `.pbix` file to explore the interactive dashboard.
